## Problem

### Printing text

In the last problem, we saw how to output an integer (using fmt.Println()).
Now let's see how to output some text.
There is only one difference. All textual content should start and end with double quotes.
For eg -

```
fmt.Print("Hey")

```

## Task
- Replace the _ (underscores) in the editor with the text "I love GO" to output "I love GO".

## Solution

**Language:** Go  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-10-28T13:55:17.770Z  

```go
package main
import "fmt"

func main() {

    fmt.Print("I love GO") //Replace the _ (underscores) with "I love GO"
}

```
